# คู่มือผู้ใช้ — MOF PSDG AI Chatbot

เอกสารนี้สำหรับผู้ใช้ทั่วไปที่ต้องการใช้งานระบบ Chatbot

## การเข้าใช้งาน

1. เปิดเบราว์เซอร์และเข้าไปที่เว็บไซต์ Chatbot (ตามที่ผู้ดูแลระบบแจ้ง)
2. หน้าต้อนรับจะแสดงข้อความต้อนรับและตัวอย่างคำถาม
3. คลิกปุ่ม "เริ่มต้นสนทนา" เพื่อเริ่มถามคำถาม

## การถามคำถาม

1. พิมพ์คำถามในช่องข้อความด้านล่าง
2. กดปุ่ม "ส่ง" หรือกด Enter เพื่อส่งคำถาม
3. รอคำตอบจากระบบ
4. คำตอบจะแสดงพร้อมแหล่งอ้างอิง (ถ้ามี)

### ตัวอย่างคำถามที่สามารถถามได้

- "ภารกิจของกลุ่มพัฒนาระบบบริหารคืออะไร"
- "PMQA คืออะไรและมีประโยชน์อย่างไร"
- "ระบบราชการ 4.0 คืออะไร"
- "ข้อมูลติดต่อของหน่วยงานคืออะไร"

## การดูแหล่งอ้างอิง

เมื่อระบบตอบคำถามที่มีแหล่งอ้างอิง จะมีแผงแสดงแหล่งอ้างอิงทางด้านขวา คุณสามารถ:
- คลิกปุ่ม "แหล่งอ้างอิง" เพื่อเปิด/ปิดแผง
- ดูชื่อเอกสาร, หน่วยงาน, หมายเลขหน้า, และข้อความที่อ้างอิง

## ข้อจำกัดของระบบ

1. ระบบตอบคำถามได้เฉพาะข้อมูลที่มีอยู่ในฐานความรู้เท่านั้น
2. หากไม่พบข้อมูลที่เกี่ยวข้อง ระบบจะแจ้งว่าไม่พบข้อมูล
3. ระบบไม่แต่งข้อมูลขึ้นมาเอง
4. ข้อมูลบางอย่างอาจไม่ทันต่อเหตุการณ์ ควรตรวจสอบวันที่ของเอกสารอ้างอิง

## เคล็ดลับการใช้งาน

- ถามคำถามที่ชัดเจนและเฉพาะเจาะจงจะได้คำตอบที่แม่นยำกว่า
- หากไม่พอใจกับคำตอบ ลองตั้งคำถามใหม่ด้วยคำพูดที่แตกต่าง
- คุณสามารถเริ่มบทสนทนาใหม่ได้ทุกเมื่อโดยคลิกปุ่ม "เริ่มบทสนทนาใหม่"
