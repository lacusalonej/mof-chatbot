# การกำหนดค่า AI — MOF PSDG AI Chatbot

เอกสารนี้อธิบายการตั้งค่าผู้ให้บริการ AI และพารามิเตอร์ต่างๆ

## AI Provider ที่รองรับ

ระบบรองรับผู้ให้บริการ AI หลายราย สามารถเปลี่ยนได้โดยการแก้ไขไฟล์ `.env`

| Provider | ค่าใน `.env` | คำอธิบาย |
|----------|-------------|----------|
| Demo Mode | `demo` | ไม่ใช้ AI จริง สำหรับทดสอบ Workflow |
| OpenAI | `openai` | ใช้โมเดล GPT จาก OpenAI |
| Anthropic | `anthropic` | ใช้โมเดล Claude จาก Anthropic |
| Ollama | `ollama` | ใช้โมเดลที่รันในเครื่องผ่าน Ollama |

## การกำหนดค่าในไฟล์ `.env`

```env
# เลือกผู้ให้บริการ AI
AI_PROVIDER=demo

# OpenAI
OPENAI_API_KEY=sk-your-api-key-here
OPENAI_MODEL=gpt-3.5-turbo
OPENAI_EMBEDDING_MODEL=text-embedding-3-small

# Anthropic
ANTHROPIC_API_KEY=sk-ant-your-api-key-here
ANTHROPIC_MODEL=claude-3-haiku-20240307

# Ollama (รันในเครื่อง)
OLLAMA_BASE_URL=http://localhost:11434
OLLAMA_MODEL=llama3.2
```

## พารามิเตอร์การสร้างคำตอบ

| พารามิเตอร์ | คำอธิบาย | ค่าเริ่มต้น | ช่วงค่า |
|-------------|----------|-----------|--------|
| Temperature | ความคิดสร้างสรรค์ของ AI (ยิ่งสูงยิ่งสร้างสรรค์ แต่อาจไม่แม่นยำ) | 0.7 | 0.0 - 1.0 |
| Maximum Tokens | จำนวนโทเค็นสูงสุดในคำตอบ | 2000 | 100 - 4000 |
| System Prompt | คำแนะนำระบบสำหรับ AI | (ดูด้านล่าง) | - |

## System Prompt ตัวอย่าง

```
คุณคือผู้ช่วยตอบคำถามสำหรับกลุ่มพัฒนาระบบบริหาร กระทรวงการคลัง
คุณตอบคำถามเป็นภาษาไทยเป็นหลัก

กฎสำคัญ:
1. ห้ามแต่งข้อมูลราชการหรือสร้างระเบียบปลอม
2. หากไม่พบข้อมูลในฐานความรู้ ให้บอกว่าไม่พบข้อมูล
3. ทุกคำตอบที่เป็นข้อเท็จจริงต้องแสดงแหล่งอ้างอิง
4. หากข้อมูลในเอกสารเก่า ให้แจ้งวันที่ของเอกสาร
5. ห้ามอ้างอิงหน้าของเอกสารที่ไม่มีอยู่จริง
```

## Demo Mode

หากยังไม่มี API Key ให้ตั้งค่า `AI_PROVIDER=demo` ระบบจะทำงานในโหมดสาธิต ซึ่งจะไม่เชื่อมต่อ AI จริง แต่สามารถทดสอบ Workflow ของระบบได้ทั้งหมด

**คำเตือน**: Demo Mode ไม่ใช่ระบบ AI จริง ไม่ควรใช้ในการให้ข้อมูลจริงแก่ผู้ใช้งาน
