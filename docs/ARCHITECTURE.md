## รายละเอียดแต่ละเลเยอร์

### Frontend Layer
- **Chatbot UI**: หน้าแชทหลักสำหรับผู้ใช้ทั่วไป ใช้ HTML/CSS/JS แบบ Vanilla รองรับมือถือ
- **Admin Dashboard**: หน้าจัดการระบบสำหรับผู้ดูแล แยกจากหน้าแชทอย่างชัดเจน
- **Trial Link Page**: หน้าสำหรับผู้ที่มีลิงก์ทดลอง ไม่เปิดเผย Admin Dashboard

### Backend Layer (Python + FastAPI)
- **Auth API**: การยืนยันตัวตน, JWT tokens, จัดการเซสชัน
- **Chat API**: รับส่งข้อความแชท, จัดการบทสนทนา
- **Document API**: อัปโหลด, ดูรายการ, ลบเอกสารในฐานความรู้
- **Admin API**: สถิติระบบ, จัดการผู้ใช้, ประวัติการใช้งาน
- **Trial API**: สร้างและจัดการลิงก์ทดลองใช้งาน
- **Website API**: จัดการแหล่งข้อมูลจากเว็บไซต์

### Database Layer
- **Relational DB**: เก็บข้อมูลผู้ใช้, เอกสาร, บทสนทนา, ลิงก์ทดลอง, audit logs
- **ChromaDB**: เก็บ embeddings สำหรับ semantic search และ vector search

### AI Layer
รองรับหลายผู้ให้บริการ AI ผ่านโมดูลแยก:
- OpenAI (GPT models)
- Anthropic (Claude models)
- Ollama (โมเดลในเครื่อง)
- Demo Mode (สำหรับทดสอบโดยไม่ต้องใช้ API Key)

## รูปแบบการทำงานของ RAG

1. ผู้ใช้ส่งคำถามผ่าน Chatbot UI
2. Backend รับคำถามและสร้าง embedding ของคำถาม
3. ค้นหาข้อมูลที่เกี่ยวข้องจาก ChromaDB (vector search)
4. ค้นหาข้อความจากฐานข้อมูล relational (keyword search)
5. รวมบริบทจากทั้งสองแหล่ง (hybrid search)
6. ส่งบริบทและคำถามให้ AI Provider
7. AI สร้างคำตอบพร้อมแหล่งอ้างอิง
8. Backend ส่งคำตอบกลับไปยังผู้ใช้พร้อม citation

## ความปลอดภัย

- รหัสผ่านแฮชด้วย bcrypt
- JWT สำหรับการยืนยันตัวตน
- RBAC (Role-Based Access Control) สำหรับการควบคุมสิทธิ์
- API Key เก็บที่ backend เท่านั้น ไม่ส่งให้ frontend
- CSRF protection สำหรับการเปลี่ยนแปลงสถานะ
- Rate limiting สำหรับป้องกันการโจมตี
- Input validation สำหรับทุกข้อมูลที่รับจากผู้ใช้
- Path traversal protection สำหรับการอัปโหลดไฟล์
