# คู่มือผู้ดูแลระบบ — MOF PSDG AI Chatbot

เอกสารนี้สำหรับผู้ดูแลระบบ (Admin) ที่ต้องจัดการระบบ Chatbot

## การเข้าสู่ระบบ Admin Dashboard

1. เปิดหน้า Admin Dashboard (ตาม URL ที่กำหนด)
2. กรอกชื่อผู้ใช้และรหัสผ่านที่ได้รับจากการสร้างบัญชีครั้งแรก
3. หลังจากล็อกอิน คุณจะเห็นเมนูจัดการระบบต่างๆ

## การสร้างบัญชี Admin คนแรก

หลังจากติดตั้งระบบเสร็จ ให้รันสคริปต์เริ่มต้น:

```bash
cd backend
python scripts/init_db.py
```

สคริปต์จะขอข้อมูลต่อไปนี้:
- ชื่อผู้ใช้ Admin
- อีเมล Admin
- รหัสผ่าน Admin
- ชื่อ-นามสกุล

หลังจากสร้างแล้ว ให้เปลี่ยนรหัสผ่านทันทีหลังจากล็อกอินครั้งแรก

## เมนูหลักใน Admin Dashboard

### 1. ภาพรวมระบบ (Dashboard)
ดูสถิติของระบบ เช่น จำนวนเอกสาร, จำนวนคำถาม, จำนวน Session, สถานะระบบ

### 2. จัดการเอกสาร (Documents)
- อัปโหลดเอกสารใหม่ (รองรับ PDF, DOCX, DOC, XLSX, CSV, TXT, MD, HTML)
- ดูรายการเอกสารทั้งหมด
- ดูรายละเอียดเอกสาร
- ลบเอกสาร
- กำหนดหมวดหมู่และการจำแนกความลับ (PUBLIC/INTERNAL)

### 3. แหล่งข้อมูลเว็บไซต์ (Websites)
- เพิ่ม URL ของเว็บไซต์ที่อนุญาตให้ดึงข้อมูล
- ต้องอยู่ใน allowlist (palad.mof.go.th, psdg.mof.go.th)
- ตั้งเวลาตรวจสอบข้อมูลใหม่

### 4. คำถามที่พบบ่อย (FAQ)
- เพิ่ม, แก้ไข, ลบคำถามที่พบบ่อย
- จัดหมวดหมู่คำถาม

### 5. บทสนทนา (Conversations)
- ตรวจสอบบทสนทนาระหว่างผู้ใช้กับ Chatbot
- ดูแหล่งอ้างอิงที่ AI ใช้ตอบคำถาม

### 6. กำหนดค่า AI (AI Configuration)
- เลือก AI Provider (OpenAI, Anthropic, Ollama, Demo)
- กำหนด Model, Temperature, Maximum Tokens
- ตั้งค่า System Prompt
- ตั้งค่า ข้อความเมื่อไม่พบข้อมูล (Fallback Message)

### 7. จัดการผู้ใช้ (Users)
- ดูรายการผู้ใช้ทั้งหมด
- กำหนดสิทธิ์ (super_admin, admin, editor, viewer)
- เปิด/ปิดการใช้งานบัญชี

### 8. ลิงก์ทดลองใช้งาน (Trial Links)
- สร้างลิงก์สำหรับให้บุคคลอื่นทดลอง Chatbot
- กำหนดวันหมดอายุ
- จำกัดจำนวนการใช้งาน
- ยกเลิกลิงก์เมื่อไม่ต้องการใช้งานอีกต่อไป

### 9. ประวัติการใช้งาน (Audit Logs)
- ดูประวัติการกระทำสำคัญในระบบ
- ตรวจสอบว่าใครทำอะไร เมื่อไหร่

## สิทธิ์ของแต่ละบทบาท

| บทบาท | สามารถทำได้ | ไม่สามารถทำได้ |
|-------|------------|--------------|
| super_admin | ทุกอย่างในระบบ | - |
| admin | จัดการเอกสาร, ผู้ใช้, การตั้งค่า AI, ลิงก์ทดลอง | - |
| editor | อัปโหลดและแก้ไขเอกสาร, จัดการเว็บไซต์ | ไม่สามารถจัดการผู้ใช้หรือการตั้งค่าระบบ |
| viewer | ดูข้อมูลได้อย่างเดียว | ไม่สามารถแก้ไขข้อมูลใดๆ |

## คำแนะนำด้านความปลอดภัย

1. เปลี่ยนรหัสผ่านเริ่มต้นทันทีหลังจากล็อกอินครั้งแรก
2. ไม่แชร์รหัสผ่านให้ผู้อื่น
3. ออกจากระบบทุกครั้งเมื่อเลิกใช้งาน
4. ตรวจสอบ audit logs เป็นระยะ
5. สำรองข้อมูลฐานข้อมูลเป็นประจำ
